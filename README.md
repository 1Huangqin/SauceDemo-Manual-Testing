# SauceDemo 电商 Web 站点手工功能测试

本项目基于 SauceDemo 电商网站，进行系统级手工功能测试，完整覆盖测试点分析、用例设计、缺陷管理与回归测试全流程。

## 🛠️ 测试环境
* **操作系统**：Windows
* **浏览器**：Microsoft Edge
* **被测地址**：https://www.saucedemo.com/

## 📊 项目数据统计
* **设计用例数**：49 条（涵盖登录、商品、购物车、结算 5 大模块）
* **执行结果**：通过 31 条 | 失败 13 条 | 阻塞 5 条
* **用例通过率**：63.3%
* **发现缺陷数**：13 个（P1级 1个，P2级 2个，其余为 P3 级）
* **缺陷闭环率**：100%（已在禅道完成全生命周期流转）

## 📂 项目目录说明
* `电商测试用例.xlsx`：49 条测试用例设计（包含正向、异常、边界值逆向推导）
* `电商测试报告.docx`：包含测试执行统计与核心缺陷明细的最终总结报告
* `禅道-Bug.png`：13 个缺陷在禅道中全部闭环的截图
* `禅道测试用例-1.png` ~ `-4.png`：禅道用例执行结果全览截图

## 🚀 核心测试亮点
1. **逆向需求分析**：在无官方需求文档的情况下，通过对页面的实际操作表现，逆向推导并设计了 49 条高覆盖度测试用例。
2. **缺陷深度挖掘**：精准定位了 P1 级商品图片展示错乱，以及导致主流程阻塞的 P2 级 Remove 按钮失效、结算表单输入错乱缺陷。
3. **阻塞分析与闭环**：准确分析 2 个核心缺陷导致 4 条结算流程用例阻塞；并在禅道中完整模拟了“激活->已解决->已关闭”的企业级缺陷管理流程。
